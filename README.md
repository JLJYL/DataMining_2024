# DataMining_2024

資料探勘課程實作成果，包含期中與期末專題。

## 期中專題｜糖尿病預測

使用 KNN、Logistic Regression、Decision Tree、Random Forest、MLP 等方法進行分類與模型比較，並實作 PCA、K-means 等資料分析方法。

## 期末專題｜癌症 RNA-Seq 分類與未知類別探索

利用資料探勘技術，結合機器學習與分群演算法，對包含未知類別之 RNA-Seq 基因表現資料進行分類與分析。
